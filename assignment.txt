Task.

You are asked to develop a system to automatically locate and recognise the balls on a pool table (in images such as that below) taken with a stationary camera.  This assignment is to be coded in C++ using the OpenCV library. All of your code must go in myApplication.cpp and it must be possible to run your code simply by calling the MyApplication() function.


Sample table image.png


The assignment consists of two stages of development each of which must be followed by comprehensive testing:


Development stage 1 - Find the balls:

Given an image of the pool table your software must locate each ball on the table and return the position of the ball in table coordinates.  You must evaluate using appropriate metrics how successful your system is at addressing the task for all provided images (Table1.jpeg ... Table6.jpeg).


Development stage 2 - Recognise the balls:

Using the balls located in the previous stage, identify each of the balls as one of the numbered balls (1-15) or the white ball.  You are provided with an additional image (AllBalls.jpeg) which shows all of the balls and can be used for training purposes (as you cannot use the other images for training).  Again, you must evaluate using appropriate metrics how successful your system is at addressing the task.


Notes.

    Your approach to the problems must be general and should not be tuned to the data provided.
    You must use the same parameter settings for all images.
