* Design

I used generative AI during the research and planning phase - it was useful for aggregating
docs and to produce a coherent planning document for the process that I had in my head.

* Coding

I wrote the repository setup and general assignment setup/skeleton myself, choosing a build system and environment setup I was familiar with (nix, meson, C++ 26). Once I was happy with that and I had established a coding style, I felt comfortable to use coding agents in order to help me implement the algorithms I described to them faster, as they are able to write and refactor code to my will much faster
than I would have been able to myself.

I believe this led to a simple and nice looking railway oriented programming style for my submitting, making use of a Result monad and the recently added c++ views/ranges pipelines features to give my code a nice linear flow.

* Testing

I used coding agents to wrap the previous code in order to extend it to allow me to test over multiple transformed version of the images, rather than just the originals. Since this was not code I specifically had to submit, not was it required in the assignment, I was able to let them a little more loose on this as it's external to the core part of the assignment.

* Report writing

The report was hand written by me, and so were any in code docs. However, I did have AI proof read my report for any obvious mistakes.
